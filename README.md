# 짱구는 못말려 · 역분석 기반 웹 포팅

1997년 Windows 게임의 `SHIN.EXE`와 `RESOURCE.RES`를 분석해 만드는 네이티브 웹 버전입니다. 브라우저는 EXE를 실행하지 않으며 JavaScript와 Canvas 2D로 동작합니다.

**7개 스테이지, 미니게임 5종, 최종 보스, 엔딩·크레딧과 메인 메뉴 복귀까지 구현되어 있습니다. 구간별 자동 테스트와 일부 브라우저 플레이를 확인했으며, 처음부터 엔딩까지의 연속 플레이와 원작의 화면·속도·오디오 일치 여부는 아직 전체 검증을 마치지 않았습니다.**

## 실행

**[브라우저에서 플레이](https://ninanoV.github.io/changoo-web-port/)**

저장소에는 포팅 소스와 웹 실행에 필요한 원본 그래픽·맵·설정·음성 리소스가 포함되어 있어 내려받은 뒤 바로 실행할 수 있습니다. 원본 Windows 실행 파일, DirectX 설치 파일, CD 이미지와 기존 저장 파일은 포함하지 않습니다.

```text
Changoo (E)/
  RESOURCE.RES
  RESOURCE/
    CHAR.CFG
    *.WAV
```

로컬 실행에는 Python 3이, npm 명령과 테스트에는 Node.js 20 이상이 필요합니다. 전체 테스트에는 원본 `Changoo (E)/SHIN.EXE`, `RESOURCE/game.dat`, `RESOURCE/save.dat`가 추가로 필요합니다. 게임의 새 진행 상태는 이 파일들과 무관하게 첫 스테이지·미니게임 미해금 상태로 시작하며 브라우저의 localStorage에 저장됩니다.

GitHub Pages는 `main`에 변경 사항을 올리면 자동으로 갱신됩니다. 배포 파일에는 `index.html`, `web/`과 위 실행 리소스만 포함되며, 분석 도구·테스트·개발 문서는 포함되지 않습니다.

아래 개발용 시작 위치와 검증 메뉴 설명은 개발 기록입니다. 현재 일반 플레이 화면에서는 표시하지 않습니다.

프로젝트 루트에서:

```sh
npm start
```

[게임 열기](http://localhost:8000/)에서 **게임 시작**을 누릅니다. 원본 로고 두 장이 표시된 뒤 메인 메뉴가 열립니다. Node/npm이 없다면 `python3 tools/serve.py`로도 실행됩니다. 서버는127.0.0.1에만 바인딩하며 개발 중 이전 모듈이 섞이지 않도록 `Cache-Control: no-store`를 보냅니다. `npm install`이나 빌드는 필요 없습니다. HTML을 더블 클릭하는 `file://` 실행은 지원하지 않습니다. 이전 서버에서 열린 탭에 옛 동작이 남아 있다면 브라우저 캐시를 비우고 다시 여세요.

- 원본 메인 메뉴의 GAME PLAY를 선택하면 해금된 스테이지/미니게임 선택 화면이 열립니다. 방향키로 고르고 Space로 두 영역을 전환하며 Enter로 실행합니다. Esc는 메뉴에서 뒤로, 본편에서 일시정지입니다. 선택한 스테이지의 원본 그림·음성 연출을 재생합니다. `Space`로 즉시 건너뛸 수 있고, `Esc`로 화면·음성·시간을 함께 멈춥니다. 연출 뒤 원본 시작 좌표 `(0,0)`에서 낙하하며 시작 구간 이벤트가 수평 이동을 활성화합니다.
- `←` `→`: 이동, `↑`: 점프 (원본의 방향키 입력 대응)
- `Esc`: 본편 일시정지/계속하기·메뉴 뒤로. **메인 메뉴**: 원본 메뉴로 복귀. **처음부터**: 첫 스테이지의 검증 시작 위치로 이동
- OPTION → SYSTEM SPEED CHECK에서 자동 보정 또는 수동 속도를 선택합니다. 수동은 ←→로 조절하며 오른쪽일수록 빠릅니다. 속도는 이 브라우저에 저장됩니다. SCROLL의 A는 연속 추적, B는 화면 단위 이동이며 원본처럼 이번 실행에만 적용됩니다.
- 목숨을 모두 잃으면 GAME OVER가 표시됩니다. Space를 눌렀다 떼거나14초를 기다리면 메뉴로 돌아갑니다. 위험 지형은 피격 뒤 목숨 한 개를 소모하고 현재 스테이지 시작점으로 돌아가며, 점수·소지품은 유지합니다.
- 아이템 창과 소품에서 진입한 미니게임 중에도 원본 지형·접촉 판정은 계속됩니다. 전체 일시정지는 Esc를 사용하세요. 아이템 창은 열 때의 게임 장면을 배경으로 유지합니다.
- 초코비·캔: 닿으면 획득. 점수 100점마다 목숨 +1. 적은 내려오는 점프로 위에서 밟아 처치합니다.
- **소리 끄기/켜기**: 획득·피격·적 처치·보너스에 연결된 원본 WAV 효과음.
- 스프링은 위에서 내려오며 밟으면 높게 튀어 오릅니다. 이동 발판 위에 서서 이동할 수 있습니다.
- 닭/바퀴벌레 아이콘에 닿으면 변신합니다. 닭은 점프 후 공중에서 `Space`를 눌렀다 떼며 날갯짓하고, 바퀴벌레는 지상에서 `Space`로 돌진합니다. 피격하면 일반 짱구로 돌아옵니다.
- 첫 높은 벽을 넘은 뒤 등장인물 3명과 대화합니다. `Enter`를 눌렀다 떼면 건너뜁니다. 일시정지하면 대사와 이벤트 시계도 멈춥니다.
- 그다음 등장하는 적과의 대화가 끝나면 원래 전투 동작으로 돌아갑니다. 이 적도 위에서 밟아 처치하고 점수를 얻을 수 있습니다.
- 집 근처 초코비 연출은 회상 말풍선과 원본 음성을 포함합니다. 끝까지 보면 소품이 사라지며, Enter로 건너뛰면 원본처럼 소품이 남습니다.
- 일반 짱구는 지상에서 `Space`로 선택한 공/물폭탄을 던집니다. `Enter`로 선택 화면을 열고 `↑` `↓`로 이동한 뒤 `Enter`로 확정합니다. 메뉴를 연 동안 게임은 멈춥니다.
- 색 구슬은 엄마·아빠·흰둥이·유리 엄마·친구들·아줌마들 소환 아이템입니다. 획득 후 Enter 메뉴에서 선택하면 사용합니다. 엄마는 1개일 때 가까운 적을 공격하고, 2개 이상이면 2개를 소모해 활동 중인 적들을 공격합니다. 한 동료가 활동하는 동안 다른 동료는 소환할 수 없습니다.
- **복원 범위와 분석 근거 → 2스테이지 공격 아이템 구간**: 원본 물폭탄 배치에서 획득·발사를 확인하는 개발용 시작 위치입니다. 시작 직후 `→`를 약 1초 누르고 착지한 뒤 `Enter → ↓ → Enter`로 물폭탄을 선택하고 `Space`로 던집니다. 2스테이지의 전체 진행이 복원된 것은 아닙니다.
- **2스테이지 보스 앞으로**: 2스테이지에서만 사용할 수 있습니다. 현재 목숨·점수·소지품을 유지하고 보스 앞의 전투 상태를 초기화합니다. 아래 발판을 밟고 위 발판으로 올라 보스를 밟거나 실제 획득한 무기를 사용할 수 있습니다. 등장 대사는 건너뛸 수 없고, 처치 후 대사는 Enter, 종료 화면은 Space로 넘깁니다.
- **슈팅 전투 검증**: 원본 `shoot.map`과 진입 연출을 엽니다. 방향키로 비행하고 Space를 눌렀다 떼면 3발을 발사합니다. 적·보스·구간 대사는 연결했습니다. Headless Shell에서 자연 stage1→stage2→shooting boss→booster boss 처치→Stage 05 진입까지 단계별 테스트 시계로 확인했습니다. 일반 실시간 속도와 원작 입력 parity는 남아 있습니다.
- **2스테이지 대사 구간**: 원본 대사 트리거 앞에서 시작합니다. `→`로 진입하면 11.32초짜리 대사와 말풍선 연출을 재생하며 `Enter`를 눌렀다 떼어 건너뜁니다.
- **2스테이지 동굴 구간**: 원본 동굴의 (5000,3032) 부근에서 시작하는 개발용 확인 위치입니다. 가속하는 쥐 적을 밟고 오른쪽 하수관에서 떨어지는 장애물을 피할 수 있습니다. 소지품을 지급하지 않습니다.
- **첫 보스 구간에서 시작**: 원본 보스 방에서 기본 목숨 5개로 시작합니다. 스프링을 타고 보스를 밟되 돌진 중에는 피하세요. 보스를 처치하면 목숨 3개를 받고 소지품을 유지한 채 2스테이지로 이동합니다. 2스테이지의 원본 진입 연출이 이어지며 Space로 건너뛸 수 있습니다.
- **복원 범위와 분석 근거 → 첫 적 구간에서 시작**: 적 동작을 빠르게 확인하는 개발용 시작 위치입니다. 진행 상황을 초기화하며 원작의 메뉴 기능은 아닙니다.

- **슈팅 보스 앞으로**: 슈팅 구간에서 활성화되며 현재 목숨·소지품을 유지한 개발용 보스 시작 위치입니다. 보스의 조준탄을 피하며 Space를 눌렀다 떼어 공격합니다.
- **부스터 보스 앞으로**: 부스터 구간에서 현재 목숨·소지품을 유지하며 실제 보스 방으로 이동합니다. 보스 처치 뒤 종료 연출→다음 진입 연출→목숨 +3·일반 이동으로 이어집니다.
- **부스터 이동·발사 검증**: 다음 구간의 원본 진입 연출부터 시작합니다. 방향키로 가속하고 Space로 발사합니다. 적 2종과 보스·종료를 연결했으며 시작점부터 보스까지의 전체 경로 검증은 남아 있습니다.
- **정글 진입·낙하 검증**: 5스테이지(stage4.map)의 진입 연출과 낙하산부터 시작합니다. 진입 그림은 Space로 넘길 수 있지만 낙하·착지 연출은 끝날 때까지 조작할 수 없습니다. 착지 뒤 오른쪽으로 이동해 첫 아이템을 얻을 수 있습니다.
- **정글 적 구간 검증**: 실제 맵 (4450,4200)에서 원숭이 적·점프/밟기·야자 열매를 확인하는 개발용 위치입니다. 진행 상황은 초기화되며 장비는 지급하지 않습니다.
- **정글 첫 스프링 앞**: (2940,6232)에서 시작합니다. 오른쪽으로 조금 이동하고 점프해 덤불 스프링 위에 착지하면 높은 벽 위까지 올라갑니다.
- **정글 다리 위**: 첫 다리 조각 위 (19840,5065)에서 내려옵니다. 닿은 조각은 계속 내려가므로 오른쪽으로 건너세요. 두 검증 위치도 진행 상황을 초기화합니다.
- **정글 보스 앞으로**: 정글에서 현재 목숨·소지품을 유지하며 실제 보스 방 (24520,6232)으로 이동합니다. 자동 대사가 끝나면 위 발판에 점프해 올라간 뒤 왼쪽 덤불 스프링을 타고 두 보스를 밟을 수 있습니다. 두 보스를 모두 처치하면 목숨3개를 받고6스테이지 진입 연출로 이어집니다.
- **두더지 미니게임 아래**: 2스테이지의 실제 스프링 아래에서 시작합니다. `↑`로 한 번 점프하고, 스프링을 밟아 높이 올라갈 때 `→`로 입구에 닿으세요. 미니게임에서는 방향키를 눌렀다 떼어 3×3 칸을 선택하고 `Space`로 망치를 내립니다. 시간이 끝나거나 `F6`를 누르면 본편으로 복귀합니다. `Esc`는 일시정지입니다.
- **자동차/깃발 미니게임 앞**: 실제 소품 왼쪽의 개발용 시작 위치입니다. `→`로 닿으면 진입합니다. 자동차는 `←` `→`를 눌렀다 떼어 차선을 바꾸고 장애물을 피합니다. 깃발은 음성 지시에 따라 `↑` 흰 깃발 올리기, `←` 흰 깃발 내리기, `→` 청 깃발 올리기, `↓` 청 깃발 내리기를 입력합니다. 가만히 있으라는 지시에는 키를 떼세요. 종료하면 스테이지로 돌아옵니다.
- 미니게임 해금은 **진입 시** 저장합니다. 최초 초기값은 원본 `game.dat`의 5개 플래그이고, 이후 같은 브라우저/주소의 localStorage 기록을 사용합니다. 원본 파일은 수정하지 않습니다. 스테이지 해금은 원본 `save.dat`의 최고 진입 단계(초기값5)를 읽고, 본편 스테이지 전환 시 브라우저에 저장합니다. 위치·소지품 저장은 원본에 없습니다. 원래 선택 화면에서 본편 스테이지·미니게임을 시작하는 연결은 복원했습니다.
- **6스테이지 시작/발판/돌/공룡·스프링/박쥐**: stage5.map의 개발용 확인 위치입니다. 진행 상황은 초기화됩니다. 새 스프링은 위에 착지하면 반동이 생기며, 돌은 맞아도 없어지지 않습니다.
- **카드 미니게임 앞**: `→`로 입구에 닿으면 18장 짝맞추기를 시작합니다. 방향키를 눌렀다 떼어 이동하고 `Space`로 선택합니다. 9쌍을 맞추거나 4번 틀리면 본편으로 돌아옵니다. `Esc`는 일시정지이며 원본 카드 게임에는 F6 복귀 처리가 없습니다.
- **6스테이지 대사/종료 앞**: `→`로 표식에 진입합니다. 일반 대사는 자동 종료하거나 `Enter`를 눌렀다 떼어 넘깁니다. 마지막 종료 연출은 자동으로7스테이지에 진입하며 목숨3개를 더합니다. 이어지는 진입 그림은 `Space`로 넘길 수 있습니다.
- **마지막 스테이지 시작/적/불**: 마지막 구간의 확인 위치입니다. 적 구간은 지상(16220,3032)에서 시작하며 `↑`+`→`로 뛰어 밟을 수 있습니다. 벽의 불은 원본처럼 장식 애니메이션이며 별도 피해 판정은 없습니다. 주변 적과 지형 판정은 유지합니다.
- **퍼즐 미니게임 앞**: `→`로 소품에 닿으면 진입합니다. 5초간 섞은 뒤 방향키를 눌렀다 떼어 **조각을 빈칸으로** 이동시킵니다. 그림을 완성하면 약2.5초 뒤 본편으로 돌아옵니다. 퍼즐에는 F6 종료가 없으며 `Esc`로 일시정지합니다.

## 남은 검증과 알려진 제한

- 7개 원본 맵의 모든 배치는 실행 핸들러 또는 원본의 명시된 무동작으로 분류했지만, 모든 오브젝트 동작과 전체 구간 완주가 검증된 것은 아닙니다. 재시작 뒤 세계 전역 상태 대조도 남아 있습니다.
- 첫 보스 구간은 원점부터 7,148틱 원본 입력 재생과 보스 처치·다음 맵 전환을 원본에서 확인했습니다. Headless Shell의 실제 게임 루프에서도 테스트 전용 60Hz 시계로 같은 경로와 stage2 진입을 확인했지만, 일반 브라우저 시계에서의 전체 경로와 그 이후 보스까지 이어지는 진행, 자동차/깃발/두더지/카드가 포함된 집부터 엔딩까지의 연속 경로는 남아 있습니다.
- 3장짜리 추가 스프링(kind 69/88/89)의 마지막 동작 프레임에서 원본 함수가 3장짜리 배열 밖을 참조합니다. 웹은 해당 프레임을 비우며, 실제 원작 화면과의 대조가 남아 있습니다.
- 피격 중 kind 71/72/74 대사에 들어가면 종료 후 조작이 멈추는 원본 버그도 재현됩니다. 이때는 **처음부터**로 다시 시작해야 합니다. kind 70은 원본에 복구 코드가 있어 정상 복귀합니다. 대사 도중 피격되는 순간의 그림은 원본의 배열 범위 밖 접근 때문에 Windows 화면 비교가 남아 있습니다.
- 목숨 0에서는 원본 `gmover.app` 게임오버 장면으로 전환합니다. 그 뒤의 메뉴 복귀는 연결했지만, 게임오버 전후 모든 전역 상태를 원본과 대조하는 작업은 남아 있습니다.
- 2스테이지 종료 화면의 마지막 전환 틱에 Space를 누르면 원본 제어가 맵 전환을 두 번 요청합니다. 이 경계 동작을 보존했으며, 연속 플레이에서의 영향은 추가 확인이 필요합니다.
- 두더지·카드의 원본 난수 수식과 상태를 유지하지만, 모든 객체의 난수 호출까지 포함한 본편 전체 난수 순서는 아직 검증하지 않았습니다.
- 보스 등장 대사 뒤 위험 지형에서 재시작하면 보스 재등장 가드가 유지되는 원본 동작이 있습니다. 보스가 사라진 경우 메인 메뉴에서 해당 스테이지를 다시 선택하세요.
- 원작 실행 속도 보정과 프레임 단위 화면 비교. 고정30Hz 대신 원본의 속도 대기값·프레임 건너뛰기와 브라우저 화면 갱신을 사용합니다. 당시 Windows의 타이머 해상도, 모든 객체의 건너뛴 그림 처리 및 실제 PC 속도 대조는 남아 있습니다.
- 자동차 원본 코스의 180~199행은 모든 차선이 막힙니다. 원본 데이터와 충돌을 보존해 일반 입력으로는 성공 분기까지 도달할 수 없습니다. 성공 분기 자체는 192행에서 시작하는 별도 경계 시험으로만 확인했습니다.
- 자동차 CD 음악 13번 트랙과 두더지 12번 트랙은 재생하지 않습니다. 현재 ISO는 61,954,048바이트의 ISO 9660 데이터 영역이고 별도 오디오 트랙이 없습니다. CAR/CRASH, 두더지 PUNCH2 효과음과 깃발의 음성/판정 효과음은 연결되어 있습니다. 실제 원작 오디오 동기 비교는 남아 있습니다.
- 카메라 전체 함수의 표시 좌표·대기 오프셋·타일 경계별 객체 검색을 대조했습니다. 원본 타일 캐시의 픽셀 결과와 모든 그림 출력 순서 비교는 남아 있습니다. 기본 모달의 지형/접촉 처리와 종료 시 재개 순서는 대조했습니다. 아이템 창 중 카메라/실제 객체 생성은 통합 대조했습니다. 겹친 모달과 첫 배경 캡처·전체 픽셀 출력 순서는 남아 있습니다.
- 동료의 공격 대상은 현재 복원한 적·보스에 연결했습니다. 나머지 적·보스의 동료 피격 처리와 기존 적/투사체의 특수 충돌 타입 2는 추가 대조해야 합니다. 새 5종의 타입 2는 원본을 대조했습니다.
- Headless Shell에서 시작부터 Stage 05 진입 연출까지 연결했습니다. Stage 05–07의 자연 플레이와 엔딩, 자연 14목숨 상태의 도달 가능성, 원작 입력 parity, 일반 RAF 시계·화면 픽셀·오디오 대조는 남아 있습니다.
- 초코비 연출 후반을 건너뛸 때 원본은 다른 그림 배열의 프레임 번호를 잠시 유지합니다. 웹은 배열 범위 밖이면 기본 자세를 표시하며, 이 짧은 구간의 원작 화면 대조는 남아 있습니다. 회상 애니메이션의 배열 경계도 실제 프레임 속도 보정 시 다시 검증해야 합니다.

